## 实现边界

- **整页与逐格两个策略分开。** 手册六层prompt针对整页一次生成；task-launcher有逐格出图后拼页路径，不能把“Exactly THREE frames”发给每格。先由任务选择生成策略，再编译对应prompt。
- **创作数据和API payload分开。** 原文JSON与专用jobs不可直接传当前接口。当前ScenePlan字段较薄，转换不得悄悄丢掉稳定ID、说话人、连续性与must_show等信息。
- **模板规则可选。** 2–4格、两位主要互动角色、六页节奏窗口属于创作起点，不应成为所有用户不可修改的产品硬限制。
- **用户服务配置保留。** GPT图像和聊天服务由用户设置地址/Key/模型；不得强制换模型、改大小写或刷新时覆盖私有模型。
- **凭证入口适配。** 参考手册客户端读.env的NAI，本仓库使用NOVELAI_API_KEY/NAI_API_KEY及界面Token。不要直接复制原文Windows路径或假定当前已有nai_generate.py。
- **免费资格实际查询。** 请求面积/步数/张数只是参数条件，还需要当前账号、订阅、余额与运行状态。原文规则不是永久官方保证；参考图/额外功能费用也要核对。
- **交付阶段可审计。** 至少区分planned / generated / visual_reviewed / lettering_reviewed / accepted，保留不通过原因与合理偏离。
