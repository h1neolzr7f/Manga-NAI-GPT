# 内置模型（一键包）

安装器 / 便携版**默认只打包**体积小、质量/体积比高的权重：

| 文件 | 约大小 | 用途 | 许可 |
|---|---|---|---|
| `comictextdetector.pt.onnx` | 91MB | 去字文字蒙版（避免擦到人脸等） | GPL-3.0 |

**不打包**（请在「服务设置 → 本机模型」按需下载，支持断点续传与镜像）：

| 模型 | 约大小 | 原因 |
|---|---|---|
| 漫画微调 LaMa | 196MB | 体积大；纯色气泡已由气泡填底色覆盖 |
| 通用 LaMa | 197MB | 与漫画版二选一即可 |
| SAM 2.1 tiny | 149MB | 智能点选可选；未接 MobileSAM |
| Manga OCR | 424MB | 过大，不适于塞进安装包 |

开发时本目录可为空；CI 的 `prepare-installer.ps1` 会下载 CTD 到 staging 的 `bundled_models/`。
运行时查找顺序：环境变量 → `bundled_models/` → 用户缓存。
